The first release, `22a647c`, deployed to beings.earth with measured Front Range terrain, sculpted sprite habitats, a glass field journal, scoped private map entries, self-service sensing review/refresh, persistent private Blob storage, and transactional MCP pause enforcement. A follow-up adds actual private journal/treasury reads, explicit write eligibility, guarded recurring stewardship, and live-evaluation fixes.

## Validation scope

The broad web run passed 96 test files and 809 tests; its single failure was a typo in a newly written test helper, subsequently corrected and verified by all five sensing tests. Further focused runs passed 32 dashboard/MCP/privacy tests, 47 storage/status tests, 24 bounty tests, 22 attestation/payout/reputation tests, eight needs tests and 11 world-location tests. These overlapping counts must not be summed as a unique test total. The runtime suite passed 84 tests. Typecheck passed; Vercel completed the production build with its actual environment. Local compilation succeeded, but local page-data collection appropriately refused absent production secrets.

Desktop and narrow-window browser inspection verified rendered terrain, sprite visibility, navigation and live sensing controls. Device-wide GPU performance, independently surveyed elevation accuracy and the complete mobile/accessibility matrix remain unmeasured. Close-up vegetation and habitats are artistic; regional DEM relief is exaggerated 2.5×.

## Still required for full PRD acceptance

Boulder Creek remains private and paused. Two independently accepted guardians, consultation, wallet enrollment, a funded testnet Safe, real evaluator/signature integration and a complete approved payout lifecycle are not established by this release. Base Sepolia is the user's chosen first settlement environment; no real-money spend is authorized. Supplied wallet candidates are not treated as signed guardian acceptance.

Stripe/fiat conversion, wallet-provider production configuration, Commons credentials, real evidence scanning/signing, actual ecological outcome windows and the full adversarial evaluation remain separate acceptance steps. Grant rounds and coalition treasuries do not have a deployed lifecycle. The current HTTPS runtime serves one being per configured port set; summon staging voice previews are not hosted by it. The older donor helper falls back to its honest template; trusted scheduled donor drafting uses the separate background path. Reliable platform ingestion of local usage/guard logs still needs idempotent delivery.

See `docs/production-agent-audit.md` for the requirement-by-requirement proof matrix and `docs/runtime-implementation.md` for schedules, stopping commands and the Mac's availability limits. A green connection is not a claim that these remaining workflows have occurred.
