## Still required for full PRD acceptance

Boulder Creek remains private and paused. Two independently accepted guardians, consultation, wallet enrollment, a funded testnet Safe, real evaluator/signature integration and a complete approved payout lifecycle are not established by this release. Base Sepolia is the user's chosen first settlement environment; no real-money spend is authorized. Supplied wallet candidates are not treated as signed guardian acceptance.

Stripe/fiat conversion, wallet-provider production configuration, Commons credentials, real evidence scanning/signing, actual ecological outcome windows and the full adversarial evaluation remain separate acceptance steps. Grant rounds now implement draft/open/closed states, application deadlines and same-being proposal applications, with audit events and existing bounty links. Their planning budgets do not reserve funds or authorize awards. Public opening and applications remain blocked for paused or unconsulted beings. Coalition treasuries and retroactive grant allocation remain future work. The current HTTPS runtime serves one being per configured port set; summon staging voice previews are not hosted by it. The older donor helper falls back to its honest template; trusted scheduled donor drafting uses the separate background path. Version-one telemetry ingestion and acknowledgment-based delivery are implemented; production activation and receipt verification are recorded below once performed.

See `docs/production-agent-audit.md` for the requirement-by-requirement proof matrix and `docs/runtime-implementation.md` for schedules, stopping commands and the Mac's availability limits. A green connection is not a claim that these remaining workflows have occurred.
