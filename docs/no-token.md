# No token, ever

Kami never issues a token. Not for governance, not for reputation, not for cosmetics, not for access. There is no launchpad, no "river coin", no points that convert to anything, and no valuation of a creek.

Why: as of 2026-09-05 no verified project represents an ecosystem with sensor grounding and a wallet; the ones that claim to are trading bots. Token governance was the failure mode of the projects that came before this one (PRD §2). The track record here is built from EAS attestations of verified work, which anyone can recompute (`packages/reputation`).

What money does exist: USDC held in a Safe signed by human guardians, donated by people who receive a monthly report of exactly what it did. The agent proposes payouts and cannot sign. See `docs/planning/01-PRD.md` §7 and §13 #8.

If you see anything claiming to be a Kami token, it is a scam.
